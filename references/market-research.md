# 市场调研：找对标、拆做法、给选项

需求调研问的是「使用者想要什么」。市场调研回答的是「别人做这件事时，已经踩过哪些坑、有哪些更好的做法」。两件事在每个阶段同时做。

调研的产出只有一种：**带来源的选项**。不是报告，不是综述。使用者要的是「这一块有三种做法，推荐第一种，因为……」。

## 每个阶段查什么

| 阶段 | 查什么 | 带回什么 |
|---|---|---|
| 1 立项 | 目标市场里做同一件事的产品有哪些；用户怎么评价它们 | 3～5 个对标；它们各自的定位和被吐槽最多的地方 |
| 2 流程和状态 | 对标产品的主流程：几步、哪里要登录、哪里要等待 | 流程上值得借的做法（比如先体验后登录） |
| 3 页面结构 | 对标产品的页面从顶到底放了什么 | 每个对标的页面大纲；共同有的组件、只有个别有的组件 |
| 4 组件规格 | 具体某个组件别人怎么做：状态、文案、边界处理 | 2～3 种做法和各自的取舍 |

## 怎么找对标

按这个顺序找，凑够 3～5 个就停：

1. **使用者点名的。** 他说「对标 X」，X 排第一。
2. **目标市场的头部产品。** 用「品类 + 国家」在当地的应用商店和搜索引擎里查，看排在前面的。
3. **国际上公认做得好的。** 同品类里常被当作范例的产品。
4. **相邻品类里把这个组件做得好的。** 比如做倒计时，电商大促页比抽奖工具做得成熟。

每个对标记四样：名字、链接、在目标市场的位置（头部还是新进入）、你实际看了它的什么（官网、应用商店页面、真实产品页面）。

## 怎么拆

**拆页面结构**　打开对标的真实页面，从顶到底记下每一块是什么，写成和 PRD 一样的大纲格式。两三个对标的大纲并排放，共同有的组件多半是这个品类的必备项，只有个别有的是它的差异点。

**拆组件**　盯着一个组件看这几样：

- 有几种状态，每种状态显示什么。
- 文案怎么写的。
- 数据少的时候、内容长的时候怎么处理。
- 点了之后发生什么。

能截图就截图，存到项目目录的 `调研/` 文件夹，文件名写清是谁的哪一块。

**看用户评价**　应用商店的评论、社区里的讨论，专看差评。差评里反复出现的问题，就是使用者的产品可以做得更好的地方，也是验收标准的来源。

## 怎么给选项

每次给使用者 2～3 个方案，用同一个格式：

```
这一块（社交证明）有三种常见做法：

A. 头像堆叠 + 参与人数（推荐）
   谁在用：X、Y（附链接）
   好处：一眼看到「有真人参与」
   要注意：人少的时候反而劝退，要配冷启动处理

B. 滚动的参与动态
   谁在用：Z
   好处：页面有动感
   要注意：数据少时会重复

C. 只显示数字
   好处：最简单
   要注意：没有头像，可信度弱

推荐 A：你的核心价值里有「高信任」，头像比数字更能建立信任。
```

规矩：

- **推荐要和第 1 章挂钩。** 理由引用使用者自己定的核心理念或核心价值，他更容易判断你的推荐对不对。
- **每个方案都写「要注意」。** 没有代价的方案不存在，只写好处等于替他做了决定。
- **选项不超过 3 个。** 查到 5 种做法，就先合并相近的。

使用者选定后，写进 PRD；在附录 B 决策记录里记一笔，「谁定的」写「采纳建议」或「使用者」。

## 来源和诚实

- **看过才算来源。** 打开过页面、看过截图，才能写「X 是这么做的」。搜索结果里的一句摘要不算。
- **写明日期。** 产品会改版，调研记录写上是哪天看的。
- **分清三种说法：**
  - 「X 是这么做的（链接，日期）」：你看过。
  - 「这类产品通常这么做」：经验，没有具体来源，要标「经验建议，未核实」。
  - 「我没查到」：就这么说。
- **不编造数据。** 没有来源的转化率、用户量、市场份额，一个都不写。

## 调研做不了的时候

没有联网工具、页面打不开、要登录、遇到人机验证，都会发生。按这个顺序退：

1. 换一个入口：官网打不开就看应用商店页面，或者别人写的测评（标明是二手信息）。
2. 请使用者帮忙：让他给对标的名字、链接，或者直接发截图。他多半比你更熟悉这个市场。
3. 用 `references/component-patterns.md` 里的经验给建议，标「经验建议，未核实」。

不要因为查不了就跳过「给选项」这一步，也不要绕过网站的访问限制。

## 调研记录怎么存

项目目录下建 `调研/`：

```
调研/
├── 对标清单.md        ← 每个对标：名字、链接、位置、看了什么、哪天看的
├── 页面结构对比.md    ← 各对标的页面大纲并排
└── 截图/
```

PRD 正文里不放调研过程，只放结论。1.2 的「对标产品」写清对标谁的什么；附录 B 记下哪些决定采纳了调研建议。
